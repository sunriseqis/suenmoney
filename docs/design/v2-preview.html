本方向已被 v3「夜间霓虹 M3」取代，见 suenmoney-v3-design-system.md 与 v3-neon-m3.html。

⚠ 图形已内联为同一份 <symbol> + <use> —— 真正的单文件，拷到任何地方双击都能看，不依赖同目录的 candidates/*.svg，也不怕预览器拦截外链。

这一页要做的事只有一个：让你在几秒钟内判断「换皮方向对不对」。 上面是 Logo 在真实位置的样子（含家族并排），下面是同一屏内容两套皮并排 + 三屏新皮实样 + 深色一屏。 全部是静态手绘，不是实现；数字是你演示库里的量级（¥3,089 / 房贷 ¥2,800）。

新皮代号 哑光账本（Matte Ledger）：与 SuenMusic 的哑光硬件同族 —— 深哑光底 #17181B、蚀刻发丝线 #2A2C30、琥珀只做「待处理」语义； 为账本另加三件东西：纸感浅色、金额排版三级、45° 折角记号。

这一屏的三个规矩

1. 一行一项，不换行。「日」占一列（大数字 + 星期小字），把 12 行连起来就是一条竖直的日轴 —— 账本的「行」感来自这里，而不是靠分割线。

2. 金额右对齐成一列。所有金额最后一位数字画在同一个 x 上（tabular + 右对齐）， 扫一眼就能比大小。这条比任何配色都更像「记账」。

3. 分类色只落在 20px 的方角块上。不铺底、不染行、不染色条；色相从 8 个收敛到 6 个 更「账本」的颜色（去掉了霓虹粉与荧光青）。

改了什么

金额带。键盘顶上一条窄带：左「本月已支出」、右「这笔后余量」。记账时人真正想知道的是 「我这个月到哪了」，不是「我敲了几位」。

入账键是折角。不靠色块面积，靠形状——和卡片、和 logo 同一个 45°。 全屏折角出现两次（卡片一次 + 这里一次），正好卡在「一屏 ≤2 次」的纪律上。

数字更大、键更方。数字键圆角收到 7px、字号 16、tabular；左列支付方式用凹槽底 （--sunken）与数字键拉开层次，这是原来「浮起白卡 vs 平铺」的替代做法。

六 · 令牌对照（逐条改了什么、为什么）

项现在v2为什么改
画布 / 卡片 #f3f4f6 ／ #ffffff #EFEBE3 ／ #FBF8F2 冷灰 → 纸白。这一条决定了整站「温度」，也是换皮最容易感知的一处
描边 #e5e7eb 冷灰线 #DCD5C7 暖发丝线 暖底配冷线会「脏」；线宽统一 1px，只做分隔不做装饰
主色 #3b82f6 / 填充 #2563eb #4C8DFF / 填充 #2E5FB8 往「墨水蓝」压一档：蓝更沉，和纸底更搭；纯图形与填充继续分开（过 AA 那条不变）
琥珀 #f59e0b（当强调色用） #C98A2B 收回「只表示待处理/逾期」，不再当第二强调色 —— 与 SuenMusic 的琥珀语义对齐
分类色相 8 个（含 #ec4899 粉 / #0891b2 荧光青） 6 个（） 8 个色相在纸底上太吵；6 个够用，且每档都做过纸底对比度
圆角 / 折角 卡片 8px，无折角 卡片 10px + 右上切 10px（一级卡） 折角是这次唯一的「新记号」；纪律：一屏 ≤2 次
金额 一个大字号，符号与角分同级 三级：¥ 小上移 · 整数主字 · 角分灰 记账产品的「脸」；全部 tabular + 右对齐成列
深浅数据 各处自带 opacity-30 / bg-primary/40 统一 --ink-1..4 四档 热力/日历/进度条/堆叠条共用四档，数据质感才会统一

七 · 落地顺序（4 天可看到整站在新皮上跑）

第 1 天 定 Logo（你看这一页选 A/B/C）→ 我出真矢量母版 + `npm run icons` 全端生成（替掉那个 280KB 位图壳）。
第 2 天 令牌落成 `tokens.json` → 生成 CSS / Swift / ArkTS 三份（计划三要用）；旧令牌一次性替换，全站先「变纸变暖」。
第 3 天 金额排版系统 + 折角记号落进卡片与键盘；把 `--ink-1..4` 替换掉散落的 opacity 值。
第 4 天 四个屏（概况/流水/报表/设置）逐屏对齐 + 手机与桌面两侧截图核对，深色同步。
之后才进计划二（fnOS）与计划三（原生化）—— 两端 UI 都从这份 `tokens.json` 生成，不会再各写一套。

这一页是方向样张，不是成品：真实落地时字体仍是你现在的 Outfit + MiSans（这里用系统字体替代）， 图标矩阵、图表几何、动效都要按真实数据重画一遍。但它足以回答三个问题： 纸感对不对、金额三级对不对、折角这个记号要不要。
