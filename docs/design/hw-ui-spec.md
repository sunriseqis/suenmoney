### 1.1 必须知道的 5 条派生规则

| # | 规则 | 实现 |

| 2 | 分类图标底色 `color-mix(色 12%, 透明)`、描边 `color-mix(色 45%, 透明)` | ArkUI 无 `color-mix()` → `UiStyle.mixHex(色, surface, .12/.45)` |
| 3 | cyber 切角**四档**：卡片 14 / 按钮 7 / orb 6 / logo·主题缩略 8 | `UiStyle.CUT_CARD/CUT_BTN/CUT_ORB/CUT_LOGO` + `cutPathCommands()` |

### 1.2.1 交互边界色 `--outline-strong`（R34，实测对比度）

`theme.css` 只有 `--line/-2/-3` 三个分隔线色，**其中 cyber 的 line(#2a2a3a) 在 #12121a 上只有 1.32:1**，
直接拿来画输入框/分段/开关边界会违反"可交互控件边界 ≥3:1"。

| 令牌 | candy | cyber | 对底色对比度 |
|---|---|---|---|
| `--outline`（只做分隔线） | `#E2E8F0` | `#2a2a3a` | 1.23 / 1.32 |
| **`--outline-strong`（可交互控件边界）** | **`#1E293B`** | **`#6f6f92`** | **14.63 / 3.87** |

> `#94A3B8`(2.56:1) 只够做**分隔线**，不得用于控件边界；candy 的控件边界直接用 `#1E293B`。
> 实现：`outlineStrongOf(isCyber)` → candy `#1E293B` / cyber `#6f6f92`。

### 1.3 字体：**以 base.css 的生效值为准**（web 复审 B4）

`theme.css` 里 `--font-mono` 的 candy 值其实是 `'Plus Jakarta Sans'`（**比例字体**），
但 `web/styles/base.css:66-78` 把它桥接成了等宽族。**生效值**：

| 变量 | candy | cyber | 说明 |
|---|---|---|---|
| `--font-display` | Outfit | Orbitron | 标题/大金额 |
| `--font-body` | Plus Jakarta Sans | JetBrains Mono | 正文 |
| `--font-mono` | **JetBrains Mono** | **JetBrains Mono** | eyebrow/数字/tag/stat-l/card-cap 全用它 |

> 实现：`fontMonoOf()` 恒返回 `'JetBrains Mono'`；**不要**从生成表读 `fontMono`。

### 1.4 背景装饰层：**应用内一律不做**（web 复审 B1 + docs R38 / F12）

`theme.css` 里的点阵（candy 24px）、电路网格（cyber 52px）、全屏扫描线、
`.deco-a~d` 几何贴纸属于**预览页装饰**，`feature-inventory#124` 明写"仅预览页有，
应用内未接入"；R38 也要求高对比装饰不得降低正文对比度。→ **本客户端不实现装饰层**。

### 1.2 尺寸映射（替换 v1 的「px 照抄」）

| Web | ArkUI | 说明 |
|---|---|---|
| `Npx` | `N` vp | 密度无关单位，1:1 |
| `dvh` / `vh` | `屏高 × pct / 100` vp | 通过 `display.getDefaultDisplaySync().height / densityPixels` 取屏高 vp 后换算 |
| `env(safe-area-inset-bottom)` | `px2vp(窗口避让区 bottom)` | 抽屉底部必须让开手势条（见 §3.1） |
| `clamp(a, 6.1dvh, b)` | `Math.max(a, Math.min(b, 屏高vp * 0.061))` | 键盘键高/字号/圆角全部走这个换算 |

## §3 外壳（移动端，按 docs R02/R15/R17/R19）

```
[内容区]（无底栏、无吸顶标题条、**无品牌条、无页面标题栏**）
  └ 当前屏
      ├ 流水页：内容直接从状态栏下开始（控制行随内容滚走）
      └ 二级页（概况/报表/设置/年度报告）：同样没有标题行，关闭靠系统返回手势
[Toast] / [记账抽屉]
```

- **无底栏、无吸顶顶栏**；标题只出现一次（R19），内容里不得重复。
- **用户 2026-10-26 裁决**：顶部 logo 条与标题栏（含主题切换、`+记一笔` 按钮）**整条不渲染**，
  流水页与二级页都一样；主题切换在「设置 → 设备」，记账入口是流水页下拉手势。
- **二级页返回改用系统返回手势**（`onBackPress()`）：
  流水页（主页）→ 交系统回桌面；年度报告 → 回报表；其余二级页 → 回流水。
  不再有顶部 `‹` / `×` 按钮。
- **不渲染 build-stamp 页脚**：移动端 `.side-foot` 是 `display:none`（app.css:741），
  之前无条件渲染等于在手机底部固定吃掉 ~105px。
- **安全区**：窗口 `setWindowLayoutFullScreen(true)`，内容**铺到物理底边**
  （`expandSafeArea([SYSTEM],[BOTTOM])`），底部不再为手势条留白；
  状态栏高度由 `getWindowAvoidArea(TYPE_SYSTEM).topRect` 量出来，由内容列自己补 `padding-top`。
- 返回键：抽屉开着先关抽屉。

## §4 各屏（结构与功能按 docs；细节数值查 web 审计）

### 4.1 流水（落地页）

**控制行（R13/R14/R16）**：两行。
1. `期间 ‹ 2026-10 ›`（靠左） + `概况 报表 设置`（**靠右、不定宽、纯文字次要链接、无选中态**）
2. 搜索框（**独占并撑满**） + `筛选` 按钮

**顶卡（R20–R23）**
- 顶卡内**必须有环比胶囊**（docs 列为顶卡必备元素）：`padding:3 8; border:1.5 currentColor; radius:pill; mono 10.5/700`，
  底色用 `accent 12%`；涨跌语义只用**文字与符号**表达（`+12.4%` / `−8.1%`），不靠染色
- 两态：有未处理待办 → 两列（本月支出 + 处理提醒）；**无 → 本月支出独占整列**（同一个组件带布尔，不写两个分支）
- 提醒**默认收起**；点一下**向下展开**明细（把列表顶下去，不是浮层）；展开态**不记忆**
- **下拉记一笔的手势反馈**（2026-10-26 裁决）：
  指示器 = **应用 logo（BrandMark）+ 下方小字「记一笔」**，用「高度随进度线性增长的裁切窗口」
  **逐段展开**（不是整块出现再放大），透明度 0.35→1；拉过 60vp 松手触发
  **轻微震动**（`vibrator`, 18ms）后打开抽屉；未达阈值回缩消失。
- **只有逾期时整张顶卡吸顶**；颜色标记与吸顶互相独立
- 三档（月/年/全部）属于期间选择器，不占额外行

**月档列表（R51–R56）**
- **无组头**：列表直接就是明细
- 行内顺序：`分类图标 · 分类名/备注 · 支付方式 · 日 · 账期 · 金额`
  - 日期只写 `28日`；账期形如 `9月12日刷 · 28日还 · 16天`
  - **不得**出现"还款日"灰药丸
- 合计：**只有加了筛选**才显示 `筛选结果 N 笔 · 合计 ¥X`；无筛选时指路到本月总额
- 分页：游标 + 每段 100 笔 + 触底「加载更多」

**筛选与搜索（R62/R63/F33）**
- 筛选默认**折叠成药丸按钮**（`筛选`），**有生效条件时带状态圆点 + 数量**
- 维度：分类 / 支付方式 / 记录人 + **排序**（日期/金额）+ **金额区间**
- 搜索支持**分类名**与**跨期**（不是锁死单月）；**不做**收入/多账本/币种/标签/附件相关筛选（F33）
- 空态给「清除筛选」按钮（R64）

**年档 / 全部档（R30/R31/R58/R59/R60/F24）**
- 年档 = 12 个月格；**窄屏退化成 3×4**（同一份数据换写法，不硬塞 12 格）
- 格内**只给量**（当月合计/全年合计）：**不许**塞环图、排名、涨跌箭头（R59/F24）
- 深浅**只用强调色四档明度**：`rgba(accent, .42/.24/.12/.05)`，阈值按
  `≥1.5m / 1.15–1.5m / 0.85–1.15m / <0.85m`（相对均值），**不得引入第二种色相**（R30）
- **0 值月份不占色阶**：只有描边、无填充（R30）
- 选中态 = **`2vp` accent 描边 + `accent 5%` 底**（R31，取 R30 四档最低档 .05），**不得实色填充**
- **两段式下钻**（R58）：第一次点格 → 选中并把**下方那张卡**切到该期间（不换页、不滚动、不产生返回栈）；
  再点同一格 或 点卡上的「进入 … →」才真正下钻
- 日历**不许有图例**、不许"越深＝花得越多"说明行（R61）

### 4.2 概况（二级页，R03/R07/R66–R75）

- **是二级页**（R03），从流水页三入口进入；标题行 `概况 ×`（R17/R18），标题只出现一次（R19）。
- 一屏总览，横跨 **本月 / 今年 / 汇总** 三档（R66），换档同时换三子指标（R68）。
- **视图里不出现任何分类名**（R67）；**不放构成堆叠条**（F09/D14）—— 分类构成是报表页的活（R77）。
- **hero 底部不放提醒条**（R07）：提醒属于流水页顶卡右半格；概况只放「本月要还」这类信息层卡（R128）。
- hero：期间档位 + 期间 ✕ 大金额 ✕ 环比 → 三子指标。
- 若显示「预计月末」：**每月前 3 天不显示**，改为 `—` 并注明数据太少（R69）。
- 月度热力（R70）：最近 12 个月滚动、**单色深浅**、格内放金额、无记录显示 `—`、窄屏 **6×2**。
  色阶**复用 R30 的四档**：`accent .42/.24/.12/.05`，阈值同 §4.1（相对均值 ≥1.5 / 1.15–1.5 / 0.85–1.15 / <0.85），0 值只描边。
- 累计条（R71）：**通栏一行、不含金额**，四项 = 已记 N 天 · M 笔 · 平均 A 笔/天 · 首笔日期。
- 进度对比卡（R73）：已过 N 天 + 日均 + 进度条（对近 3 个月日均）。
- 网格内容顺序（R72）：hero → 本月要还 → 进度对比 → 热力 → 累计（年度对比/记录跨度按档位增减）。
- 提醒展开区若出现（信息层，非流水页）：每条必须有一行动作（R74）；动作后**就地消失 + 顶卡计数 −1 + 归零变单列**（R75）。

### 4.3 报表（二级页，R76–R86）

- 二级页，标题行 `报表 ×`；**按档位换整组块**：月 8 / 年 7 / 汇总 5（R76）。
- 分类构成（R77）：**环图 + 可展开二级图例**；**环图中心显示"分类数"，不显示合计**（R78）。
- 排名行（按支付方式 / 按记录人）：**中间必须有占比条**（R79）。
- 块**纵向堆叠**，块内允许两栏；桌面不分栏（R80）。
- 环图 + 图例：宽度上限、名称列定宽（R81）；图例行宽度不得随手拉满。
- 期内节奏（R82）：**月档按天折线并逐点标值** / 年档按月 / 汇总按年。
- 对照四格（R83）：月档 = 上月 / 去年同月 / 近 12 月均值 / 单笔最高；年档 = 去年 / 近 3 年均值 / 最高月 / 单笔最高；汇总档隐藏。
- 涨跌榜（R37）：涨红跌绿按变化额，阈值 **±¥50 或 ±3% 取高**。
- **还款节奏（R84）**：月档 = 「本月已刷」+「**下月要还**」两段；**年档、汇总档隐藏**
  （年档下它退化成"全年各方式占比"，没有意义）。
- **本期洞察（R85）**：月档 3 条 / 年档 3 条 / **汇总档 2 条**；句式 `{分类} {金额}（{为什么}）`，
  纯**规则引擎**生成，不接任何外部/AI 服务。
- **删掉页首大数字与「共 N 笔」**（R86）：它们归概况；报表页顶部只留档位与期间。
- 块集合（R76）：**月 8 / 年 7 / 汇总 5**，换档 = 换掉一整组块。
  汇总档（5 块）= 分类构成 / 支付排名 / 记录人排名 / 期内节奏（按年）/ 洞察（2 条）；
  **涨跌榜与还款节奏在汇总档隐藏**（无"上期"可比、跨年谈还款节奏无意义）。

### 4.4 设置（二级页，R87–R99 / R132 / R140）

- 二级页；**分 tab**（`settings-tabs` + `stab`），移动端横滑。
- **三个** tab：**账目 / 计划与还款 / 设备**（`hw` 专属裁决：web 的「数据 + 家庭」合并为「设备」）。
  - 「账目」= 分类管理 + 支付方式（R90–R92、R136）
  - 「计划与还款」= 计划卡（R121–R124）+ 待处理/已处理（R125–R127）
  - 「设备」= **主题 / 服务器 / 修改密码 / 检查更新** 四张卡
    - 主题：**三个横排 pill**（水果硬糖 / 赛博朋克 / 跟随系统），**不做 56px 大预览卡**
    - 服务器：见 §4.9
    - 修改密码 / 检查更新（`Api.health()` 显示「服务端 v{version} · 连接正常」）
- 二级分类图标**颜色跟随一级**（Web `PCatIcon` 的 `colorName` = 父分类名），图标本身仍按二级自己的名字解析。
- **不挂「数据」区**（D15/R99）：导入、导出、备份恢复、快照、危险区**一律不进移动端**（不是隐藏按钮）。
  > 唯一的例外已由用户批准：**外观**只放主题与品牌信息，不含任何导入导出。
- 分类每行**只给笔数、不给金额**（R89）；**一级分类的笔数 = 其下所有二级累计**，
  不许出现"一级 0 笔但其实下面有 7 笔"这种口径。
- 分类编辑（R90）：改名/换图标/换色收进一个面板，点行右侧图标打开，**不做行内编辑**；
  二级**不给颜色选择器**并提示「颜色跟所属一级分类走」（R91）；只允许**同深度移动**（R92）。
- 支付方式（R135）：**不给图标选择器**，图标按类型推断。
- 支付方式行：给**本月笔数**（`本月 N 笔`）+ **「合并」**入口（合并到另一个支付方式后本项停用；合并前必须二次确认，且提示历史记录会归属过去）（FI#78/#79）。
- 分类行右侧给**「停用」**（软删：有引用时只能停用，不能删除）；二级分类可**折叠/展开**（FI#77）。
- 图标列必须定宽（R137），徽位 44px 圆/方 + 12% 分类色底 + 分类色图标（R138）。
- 圆角/动效走 v3 令牌（R132）：卡 24、抽屉 24、输入 14、胶囊 999；曲线 `cubic-bezier(.2,0,0,1)`。

### 4.5 登录 / 初始化（R10）

- 无外壳；字段走 `.field/.input`；错误按类型（401 → 口令错；网络 → 连不上）。

### 4.6 记账抽屉（R100–R115）

- **贴底半屏抽屉**，移动端唯一写入入口（R100/D21）。
- 键盘（R101/R102/R103）：**自绘 5 列**（左支付列 + 右 4 列数字键），宽高比 ~1.35:1、大号加粗；
  **严禁系统数字输入法**；支付列与键盘之间有**物理分割线**；常用分类为**胶囊 + 底槽**；数字键**浮起**。
- 字段（R104/R105）：分类 = **单行字段 + 独立双列面板**（左一级垂直导航 + 右二级网格）；
  支付方式 = **单行字段 + 独立纵向抽屉列表**（展示卡片账期）。
- 数字键序（R101，15 键 + 完成跨两行 = 恰好 16 格）：`7 8 9 ← / 4 5 6 清空 / 1 2 3 完成 / 0 00 .`；「完成」用 `rowStart:3,rowEnd:5` 占右侧第 3–4 行（**没有空格子**）。
- **禁止抽屉内横向滚动滑块**（R106）。
- 键盘上方**只保留一行摘要**：常驻「本月已支出」，**不 await**，拿不到显示占位（R107）。
- 跨月必须明说（R108）：同月低调显示还款日；跨月用强调色「这笔会记在 2026 年 11 月」。
- 月份预览走 `POST /api/expenses/preview`（R109），**前端不重算账单周期**。
- 记住上次分类/支付，沿用前校验仍可选（R110）。
- 备注输入时**折叠数字键盘**并给上方辅助保存条（R111）。
- 支付快捷键名自动精炼 2–3 字；2 项平分跨行；空位给「更多」（R112）。
- 退款/分期可用条件（R113）：退款仅非分期可用；分期仅信用卡且非退款。
- 保存后闭环（R114）：新记录**滚到列表顶并高亮 1.5 秒**。
- 首次进流水页**提示一次**「下拉可记账」，之后永不再现（R115）。
- **消费日期选择器**：单行字段 + 系统日期弹窗（FI#18）；改日期后**重新取账期预览**。
- **编辑态**（FI#12–#14）：抽屉支持编辑已有记录；「删除」（**软删**，二次确认）放在**标题行右侧**；
  保存键在金额为 0 或未选分类时**禁用**，条件满足后变可用；保存后回到列表并高亮新记录。

**2026-10-26 用户裁决（覆盖上文若干条）**

- **确认键就是保存键**：键盘右下那个键**文案为「保存」**、`press` 里执行保存
  （之前它是 `OK` 且掉进数字分支，按了什么都不发生）。不可保存时置灰。
- **不再有底部按钮行**：没有「取消」，也没有第二个「保存」；关闭靠**系统返回手势 / 下拉收起**，
  保存成功自动关。编辑态的「删除」移到标题行右侧。
- **不渲染系统关闭按钮**（`showClose: false`）：它会压在内容右上角、和「退款冲销」标记一起盖住金额。
  「退款冲销」改为紧跟标题、在左侧。
- **抽屉高度 `SheetSize.FIT_CONTENT`**（贴合内容）：既不底部留白，也不把键盘撑大；键盘固定 210vp。
- **常用分类快捷条与键盘同列宽**：第一格 62vp（对齐左侧支付列）、1vp 竖线、
  后面 4 等分（对齐 `7 8 9 ←`，`columnsGap 5` / `padding-left 6` 一致），单元格高 40vp；
  **格内左图标 + 右分类名**（图标走内置 Symbol，二级颜色跟随一级）；取 5 个正好铺满一行。

### 4.7 提醒与计划卡（R116–R128）

- 三层归属（R116）：行动层跟落地页（流水顶卡） / 信息层在概况网格 / 管理层在设置计划 tab。
- 提醒一条一行，字段顺序（R117）：金额 → 期次·名称 → 多急 → 状态 → 按钮。
- 「自动入账」状态词**不可删且必须可见**（R118）；判据落在"期"级（R119）。
- 「确认」必须落库 `ack_at`（R120）。
- 计划卡身份物（R121–R124）：分类图标、期次、**12 段进度刻度**（超过 12 期压缩按比例）、下次还款日；

- 撤销（R125–R127）：入口只在计划期次列表；两套交互（左滑 60% + 行内等价按钮）；

- 移动端提醒手势（R65）：**左滑 = 确认/入账，右滑 = 忽略**，阈值 72px 且越过换词。

### 4.7.2 移动端提醒手势闭环（R65 后半）

- 左滑 = 确认/入账，右滑 = 忽略；阈值 **72px**，越过阈值时文案要换（"松开确认/松开忽略"）。
- **动作后 8 秒内可撤销**（撤销 = revert/restore，落库）。
- **自动入账（ack）不提供撤销**（它只是确认，没写支出）。
- 按钮**不进无障碍树**的只在手势态；行内等价按钮必须仍在（可达性）。

### 4.8 品牌 LOGO（R139/R140）

### 5.1 颜色纪律（R25/R27/R29/R33/R34）

| 规则 | 实现要求 |
|---|---|
| 五色职责固定 | `--danger` 只给"要动手/危险"、`--warn` 只给"临近"、`--ok` 只给"已完成"、`--accent` 是品牌强调、`--ink-*` 是文字层级；**不得互换、不得当装饰** |

| 交互边界 | 可交互控件边界 ≥ **3:1**（用 `outline-strong`），`outline` 只做分隔线 |

### 5.1.1 排版与宽度纪律（A.4 整组：R39–R49）—— ArkUI 换行行为不同，必须显式写死

| 规则 | ArkUI 实现要求 |
|---|---|
| R39 数字 | 所有金额/百分比/日期数字统一走等宽族（`fontMonoOf()`），视觉上等价 `tabular-nums` |

### 5.3 F36：跳过语义不许复用（高风险）

`跳过`（skip）**只对"需手动入账"的期次可用**；**自动入账的期次不得出现「忽略」**
—— 那等于偷偷把自动入账关掉。自动入账型期次只能「确认」（落库 `ack_at`），
且状态词「自动入账」必须可见（R118/R120）。

## §6 ArkUI 映射约定（实现纪律）

1. **单位**：CSS px → vp，数值原样照抄，不做"适配换算"。
2. **阴影**：`parseShadow()` 把 `"3px 3px 0 #E9EEF6"` 转 `{offsetX:3, offsetY:3, radius:0, color}`。
3. **圆角**：`radiusOf(tokens, isCyber, candyValue)`；cyber 一律 0。
4. **切角**：cyber 用 `.clipShape(new Path({commands}))` 复刻 `polygon`，不得用圆角近似。
5. **字体**：一律走 `fontDisplayOf/fontBodyOf/fontMonoOf`，禁止裸写族名。
6. **`@Builder` 参数**：动态内容**必须**单参数对象 + `$$`（多参数不刷新，已踩坑）。
7. **主题**：`@StorageLink(THEME_STORAGE_KEY)` + `tok()`，禁止 `@State tokens` 快照。
8. **金额**：整数分；显示才除 100；退款为负、不加色。
9. **禁止**：Emoji、说明式文字、整卡语义色、底部 Tab、悬浮球、系统数字键盘、桌面元素（表格/构成卡/顶栏动作）。
