# v6 布局重组方案（2026-10-22 用户授权：可完全打乱重组）

> 授权原话：「我给你最大的权限，你可以完全打乱重组所有页面、功能、卡片、项目的组合，
> 只要保证所有功能都在即可。」

## 一、现状问题

- **概况页是孤岛**：要点顶栏「概况」才能看汇总，而落地页（流水）顶部只有一张小卡。
- **卡片按技术域分**（分类/支付/计划/数据），不按「用户想干什么」分。
- **流水页**：月档列表 + 年档日历 + 搜索，三个世界混在一页，靠 tab 切。
- **设置页**：5 个 tab 里「系统」tab 塞了主题+服务端+数据+更新四摊事。

## 二、重组原则

1. **落地页 = 流水**（记账 App 90% 时间在记和看流水）——顶卡给全信息密度。
2. **一屏答完两个问题**（这月花了多少 / 花在什么上面）——不需要点去「概况」。
3. **卡片按意图分组**，不按技术域。
4. **所有功能必须保留**（逐条核对，见 §五）。

## 三、新结构

### 流水页（落地页，四个区）

```
┌─ 顶卡（sticky）────────────────────────────────────────┐
│ label「本月支出」  ¥3,089.80   [▲+12.4%]   [1 期逾期]  │  ← 大数字+环比+待办入口
│ ▁▂▃▅▇ 堆叠条：餐饮71% 医疗11% 购物7% 娱乐6% 交通5%      │  ← 构成一屏答完
└───────────────────────────────────────────────────────┘
┌─ 控制行：期间 ▾ │ 按月/按年/全部 │ 搜索 │ 筛选 │ 排序 ──┐
├─ 列表（月档）/ 12 格日历（年档）/ 年历（全部档）──────────┤
├─ [构成卡] 分类/支付/记录人/节奏 四维切换 ────────────────┤  ← 从概况搬来
├─ 加载更多 ──────────────────────────────────────────────┤
└───────────────────────────────────────────────────────┘
```

**搬来的**：构成卡（原概况独有，但它是「花在什么上面」的直接答案，必须贴着流水）。
**待办提醒**：从顶卡内嵌胶囊 → 顶卡右侧独立 chip，点开是动作面板（原桌面 popover 逻辑保留）。

### 概况页（原「一屏总览」→ 改成「洞察页」）

```
┌─ ① 本期事实卡（大金额 + 环比 + 日均/笔数/预计月末 三格）  ─┐
├─ ② 双列：本月要还（信用卡明细） │ 支出进度（计划还款）      ─┤  ← 原「当期事实」
├─ ③ 月度热力（12 个月）                                      ─┤
├─ ④ 累计条                                                  ─┤
└─ ⑤ 年度对比（年档）/ 记录跨度（全部档）                       ─┘
```

去掉「大 Hero 占半屏」——洞察页不需要 Hero，直接上信息。

### 报表页（原 6 卡 → 按「看结构」重排）

```
┌─ ① 分类构成（环图 + 明细，占主位）                          ─┐
├─ ② 双列：期内节奏（周分布） │ 还款节奏                       ─┤
├─ ③ 涨跌榜                                                  ─┤
├─ ④ 本期洞察（文字结论）                                      ─┤
└─ ⑤ 年度报告横幅入口                                          ─┘
```

### 设置页（5 tab → 3 组，按意图）

| 新组 | 内容 |
|---|---|
| **账目** | 分类 / 支付方式 / 计划与待办 |
| **数据** | 导入 / 导出 / 备份恢复 / 主题 / 服务端（原生壳） / 更新 |
| **家庭** | 成员账号 / 我的账号 |

原「系统」tab 拆开：主题并到「数据」组头部（它属于应用设置），服务端设置挪到「数据」组尾部。

## 五、实施顺序

1. 流水页：顶卡加堆叠条 + 构成卡下移 + 待办 chip 独立化（最大一块，先做）
2. 概况页：去 Hero，改「本期事实卡」开头
3. 报表页：区块顺序重排（只动 DOM 顺序，不动内容）
4. 设置页：tab 重组（3 组）
5. 全量功能核对 + check + 部署
