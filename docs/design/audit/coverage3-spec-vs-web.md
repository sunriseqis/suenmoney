> **对象**：`docs/design/hw-ui-spec.md`（415 行，§0 已声明 docs 为需求真值、§1.3 字体取 base.css 生效值、§1.4 应用内不做装饰层）

> **两把尺子（避免把"复核状态"和"阻断"混为一谈）**
> - **复核尺**：上一轮那一条的**最小修复是否做完**（做了一半 = 部分）。
> - **阻断尺**：实现者拿着两份文件**能否做对**。
>   - `E1` = 规范给了值，但与审计冲突、且 §0.1 没有对应 D 编号 → **会主动做错**；

>   - `E3` = 结构/形态未定（做与不做、放哪一行），导致骨架层面二义。
>   - ±1vp 级偏差（Tag 字号、Chip 内距）与"已有全局指针可救"的缺值，一律记**必修但不计阻断**。
