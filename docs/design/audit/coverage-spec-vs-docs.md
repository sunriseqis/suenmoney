# 覆盖核验：`hw-ui-spec.md`（鸿蒙端 UI 规范 v1）vs `docs-ui-rules.md`（146 R + 36 F + 元素/页面清单）

> **核验性质**：只比对、不改文件、不写代码。
> **被核对象**：`docs/design/hw-ui-spec.md`（196 行，下称"规范"，行号 `spec:NN`）。
> **基准**：`docs/design/audit/docs-ui-rules.md`（1350 行，下称"docs"，行号 `docs:NN`）。
> **辅助核对**：`docs/design/audit/web-ui-inventory.md`（规范大量以"照 Web"方式委派，需核实委派是否成立）。
>
> **判定口径（严格三分，不用"感觉"）**
> - **覆盖**：规范里有**可执行要求**（数值 / 结构 / 明确禁止 / ArkUI 映射），或规范 §0 对该冲突给出了明确裁决。
> - **弱覆盖**（**不计入覆盖**）：仅指向别的文件（"照 web 审计 C.6"）、或只能由总原则"1:1 照搬"反推、或数值与 docs 不同但未裁决。**不可执行 → 不算覆盖**。
> - **未覆盖**：全篇无对应条款。
>
> **总计**：覆盖 **31** / 弱覆盖 **25** / 未覆盖 **90**（31+25+90 = 146）。
> 换言之：**不达标 115 条**（弱覆盖 25 + 未覆盖 90）。
