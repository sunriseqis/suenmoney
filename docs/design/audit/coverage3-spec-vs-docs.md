## 判定口径

| 判定 | 定义 |
|---|---|
| **覆盖** | 规范有成文要求且可据此判对错（结构 / 数值 / 明确禁止）；数值细节可委派 `web-ui-inventory.md`。§0 的 D1–D22 视为有效覆盖。 |
| **弱覆盖** | 触及该主题但缺可执行要求（只有 R 编号、只有半条、或给了反向数值）。 |
| **未覆盖** | 完全没有对应成文要求。 |
| **作废** | §0.2.1 明确声明不再要求覆盖，且本轮确认作废理由成立（详见 §四）。 |
