# 用户裁决的偏差（不按 Web 实现，且不算缺陷）

> 这些是**用户当面拍板**的地方，与 Web 移动端现状**故意不同**。
> 对账（`2026-10-27-web-vs-app.md`）时，凡命中本表的差异一律记为「按裁决」，**不得当缺陷上报**。
> 新增条目必须写出裁决时间与用户原话要点。

## 反例：曾经做过但不成立、已回滚的偏差

| 项目 | 曾经的错误做法 | 结论 |
|---|---|---|
| 换服务器后清 token 跳登录页 | 认为是「换后端要重登」 | **错**。suenmusic 明确：多条路径指向同一套后端（同 DB / 同 JWT），换路径不需要重新登录。已回滚 |
| 键盘 `layoutWeight(1)` 撑满抽屉 | 为了消掉底部空白 | **错**，键盘被拉得过大。已改为固定 210vp + 抽屉 `SheetType.FIT_CONTENT` |
