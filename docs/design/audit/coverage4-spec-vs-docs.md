## 判定口径（与第二轮/第三轮一致，本轮把"阻断"分级写死）

| 档位 | 定义 |
|---|---|
| **覆盖** | 规范有成文要求且可据此判对错（结构 / 数值 / 明确禁止 / 可 dump 的判据）。数值细节可委派 `web-ui-inventory.md`。§0 的 D1–D22 视为有效覆盖。 |

| **未覆盖** | 完全没有对应成文要求。 |
| **作废** | §0.2.1 明确声明不再要求，且作废理由成立。 |
| **阻断** | ①照规范实现**必然违反**某条 R/F；或②docs 明确的**功能/禁令在原生端有真实触发路径**且无归宿；或③**机械验收必需**的判据缺失。 |
