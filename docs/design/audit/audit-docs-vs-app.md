### 4.2 阻断数

**阻断 14 项**（判定口径：违反禁止项，或"核心功能规则未实现"）：

**移动外壳 + 流水页 + 记账抽屉三块已经站住（A.1+A.2+A.5+A.9 合计已实现 37/56，未实现仅 R08/R23/R58/R64/R65）**；缺口集中在 **报表的档位化块集合**、**概况的信息层（进度对比 / 预计月末 / 三子指标随档）**、**计划期次的撤销与恢复闭环**、**提醒的移动手势**，以及**日历的真实形态（深浅四档 + 两段式下钻）**。建议按阻断清单先补 F36 + R125/R127/R65 三条闭环，再补 R58/R30/R73/R64。
