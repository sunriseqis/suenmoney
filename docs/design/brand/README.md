# 品牌标记（v3 定稿）

**字形来自用户原版**：4×5 格子矩阵，**11 亮 + 9 空**，五段五个色。
上横 3 格（薄荷）→ 左竖 1 格（电紫）→ 中横 3 格（电光蓝）→ 右竖 1 格（荧光柠）→ 下横 3 格（霓虹粉）。

> **翻新纪律**：字形逐格照抄。只允许改四件技术问题 —— 方形画布、去掉三层描边、
> 发光由「逐格两次绘制」改为「分组模糊一次」、圆角收敛成两档。
> **不许重排格子、不许改色序、不许换字形。**

## 四个形态与尺寸阈值

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `mark.svg` | **≥32px** | 1024² 方形母版。iOS / 鸿蒙 / fnOS 图标、启动图、桌面、顶栏 logo |
| `mark-small.svg` | **<32px** | 只留 11 个笔画，去空格与发光。favicon 16/24、通知栏、标签页 |
| `mark-mono.svg` | 任意 | 实心 S 剪影。安卓 monochrome、鸿蒙分层前景、系统染色态 |
| `mark-header.svg` | **≥48px** | 带 header 条 + 薄荷状态点。**<48px 不出现**（会退化成噪点） |
