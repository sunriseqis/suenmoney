# 品牌标记（v3 定稿）

**这个标记是一台计算器**：机身 + 显示屏（带指示灯）+ 4×5 键盘，**亮起的键位拼出 S**。

```
机身    48,48 → 928×928  rx 220     「这是一个物件」
显示屏  212,112 → 600×176 rx 48     「计算器的脸」+ 指示灯 圆点 r20 @ 758,152（薄荷）
键盘    4×5，格 135×108 rx 34，与显示屏同宽（600）—— 原版 168/168 同理
亮键    11 亮 / 9 暗：上横(薄荷) → 左竖(紫) → 中横(蓝) → 右竖(柠) → 下横(粉)
```

> **翻新纪律**：结构照抄、键位一格不动。
> 只允许改四件技术问题 —— 方形画布、去掉描边（屏幕用更暗的 `#141222` 凹进去）、
> 发光由「逐键两次绘制」改为「分组模糊一次」、圆角收敛。
> **不许重排键位、不许改色序、不许删显示屏。**
>
> 显示屏是**语义主体**不是装饰，而且**必须有内容**：曾把它当「大尺寸才配的 header 条」删掉，
> 结果 Logo 退化成一团发光点阵；也曾只挂一个小指示灯，32px 以下仍看不出「这是屏幕」。
> 最终形态是**七段 LED「8888.88」** —— 「计算器」这件事不用猜。

## 四个形态与尺寸阈值

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `mark.svg` | **≥32px** | 1024² 方形母版。iOS / 鸿蒙 / fnOS 图标、启动图、桌面、顶栏 logo |
| `mark-small.svg` | **<32px** | 只留 11 个笔画，去空格与发光。favicon 16/24、通知栏、标签页 |
| `mark-mono.svg` | 任意 | 实心 S 剪影。安卓 monochrome、鸿蒙分层前景、系统染色态 |

## 几何（1024 坐标）

```
母版    : 机身 48,48 928×928 r220
          屏幕 212,104 600×184 r48（#141222，比机身暗＝凹）
          LED  位宽 62 / 段厚 13 / 位高 120 / 间隙 18 / 小数点 16；六位按五色相轮转
               薄荷·紫·蓝·柠·粉·薄荷，小数点柠；段用尖角六边形（七段数码管的形状）
          键盘 4×5，格 135×106 r34，间距 18/18，起点 (212,324)，与屏同宽 600
小尺寸  : LED 段加粗 13→22、位宽 70；键位改 r26 圆点；屏幕与数字保留
单色    : 屏幕 92% 白 + LED 白 + 亮键白 + 暗键 30% 白（靠明暗，不靠颜色）
```
