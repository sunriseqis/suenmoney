# 鸿蒙端：本机能力边界（Lead 自做 vs 必须上机）

> 结论先行：**代码与编译我能做；安装、运行、截图、断网、数据库实跑我做不了。**
> 依据：本机有 CLT + `devecocli`，无设备、无可用模拟器。

## 一、已具备

| 能力 | 证据 |
|---|---|
| HarmonyOS Command Line Tools 26.0.0.851 | `/opt/clt/command-line-tools`，`version.txt` |
| `devecocli 1.3.4` | `/usr/local/bin/devecocli` |
| 脚手架 | `devecocli create` 成功（API 26，bundle 三段式） |
| ArkTS 语法检查 | `devecocli check arkts` → No errors |
| 构建产物 | `devecocli build` → `BUILD SUCCESSFUL`，`.hap` 38KB |

环境变量：`export DEVECO_CLI_CLT_PATH=/opt/clt/command-line-tools`（不加会报
「DevEco Studio is not available on Linux」）。

## 二、不具备

| 缺什么 | 现象 | 影响 |
|---|---|---|
| 真机 | `device list` → No active devices | 装不上、跑不起来、截不了图 |
| 模拟器运行库 | `Emulator: libpulse.so.0 缺失` | 模拟器起不来 |
| 硬件虚拟化 | 无 `/dev/kvm` | 即便补上运行库也无法加速启动 |
| Local Test 运行器 | `devecocli` 无 test 子命令 | 31 条向量无法在 PC 上跑 |

## 四、建议的推进方式（二选一）

**A. 我继续写、上机验证交给你**
我按 H0-3 → H0-6 → H1… 把代码全部写完并保证编译通过；
每阶段给出「待上机验证清单」，你在 DevEco 机器上跑一次、贴证据，我据此放行。

**B. 我只做 H0 底座，之后整段交给 Agent**
我把 H0-1/H0-2 收尾（含主题被后续页面复用的约定），
H0-3 起由装了 DevEco 的 Agent 按任务书做，我转回纯核验角色。

> A 的收益：代码风格与口径由我一次性把握，减少来回；
> B 的收益：不出现「我写完却没人跑得过」的积压。
