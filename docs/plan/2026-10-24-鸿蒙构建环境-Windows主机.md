## 二、可复现的构建命令（已验证 BUILD SUCCESSFUL）

```bat
set DEVECO_SDK_HOME=C:\Program Files\Huawei\DevEco Studio\sdk
set PATH=C:\Program Files\Huawei\DevEco Studio\jbr\bin;C:\Program Files\Huawei\DevEco Studio\tools\node;%PATH%
cd /d C:\work\suenmoney\hw-native
"C:\Program Files\Huawei\DevEco Studio\tools\hvigor\bin\hvigorw.bat" assembleHap --mode module -p product=default --no-daemon
```

产物：`C:\work\suenmoney\hw-native\entry\build\default\outputs\default\entry-default-unsigned.hap`

### 两个必须注意的坑

1. **`DEVECO_SDK_HOME` 必须恰好指到 `…\DevEco Studio\sdk`**
   - 指到 `sdk\default` → `00303312 Cannot find the corresponding SDK version`
   - 值里带尾随空格（例如 `set X=... && ...` 的写法）→ `00303217 Invalid value of 'DEVECO_SDK_HOME'`
2. **`jbr\bin` 必须在 PATH**，否则 `00308018 spawn java ENOENT`（签名/工具链任务要 java）

## 三、源码怎么到这台上

```bat
cd /d C:\work
git clone --depth 1 --filter=blob:none --sparse https://github.com/sunriseqis/suenmoney.git suenmoney
cd suenmoney && git sparse-checkout set hw-native
```

仓库是**公开只读**可克隆的（无需凭据）。整仓克隆在这台机上很慢（>2 分钟），
稀疏只取 `hw-native` 基本瞬间完成。

## 四、SSH 访问的两条注意

1. 这台机的 `sshd_config` 里 `Match Group administrators` 那段是**注释掉**的，
   所以公钥要写 `C:\Users\rootwin\.ssh\authorized_keys`，
   写 `C:\ProgramData\ssh\administrators_authorized_keys` **不生效**。
2. 实测出现过 sshd 不响应（端口 22 可连、但读不到 banner、口令也被拒），
   怀疑连接数/账号锁定所致。**不要高频开新连接**；长任务放在同一个会话里跑。

## 五、签名（不在范围，记录事实）

`devecocli` 未随 DevEco 桌面版安装，`devecocli signature generate` 在 Linux CLT 上
需要华为账号登录。SDK 自带 OpenHarmony 签名材料（`OpenHarmony.p12`、
`OpenHarmonyProfile{Debug,Release}.pem`、`hap-sign-tool.jar`），可做本地自签，
但**用户决定不签**，因此本条不再推进。

未签名产物不能 `hdc install`；要装机请用户在 DevEco 里
File → Project Structure → Signing Configs 勾选自动签名后重新构建。
