## 三、图标策略（G6：按 iOS 可用操作）

鸿蒙端用 `sys.symbol.*`（26 条分类映射 + 支付 5 品牌）。iOS 换成 **SF Symbols**：

| 分类 | 鸿蒙 sys.symbol | iOS SF Symbol |
|---|---|---|
| 餐饮/外卖/下馆子 | `fork_knife` | `fork.knife` |
| 买菜 | `cart` | `cart.fill` |
| 交通 | `subway` | `tram.fill` |
| 打车 | `car` | `car.fill` |

| 药品 | `drug` | `pills.fill` |
| 娱乐/游戏 | `gamecontroller` | `gamecontroller.fill` |
| 电影 | `movie` | `film.fill` |

| 学习 | `book` | `book.fill` |

| 人情 | `gift` | `gift.fill` |

| 还款 | `creditcard` | `creditcard.fill` |
| **兜底** | `doc_text` | `doc.text` |

支付品牌（支付宝/微信/云闪付/京东/抖音）**没有 SF Symbol**，沿用鸿蒙端做法：
随包 SVG 资源 + `Image().renderingMode(.template)` 染色。
非品牌 4 种（信用卡/现金/银行/钱包）用 SF Symbol：`creditcard` / `banknote` / `building.columns` / `wallet.pass`。

**保底规则**：`Image(systemName:)` 若符号名不存在，iOS 会渲染空图 —— 所以映射表里每个名字都必须是我确认存在的（SF Symbols 5/6 常见符号）。若某个名字不确定，退到 `circle.dashed` 或 `questionmark.circle` 这类必然存在的。

## 四、与鸿蒙端的 11 处技术差异（实现时注意，不照搬）

| 关注点 | 鸿蒙 | iOS |
|---|---|---|
| 网络 | `http.request` | `URLSession` async/await |
| 本地库 | `relationalStore` | SQLite3（系统自带 `libsqlite3`） |
| 令牌 | `preferences` | **Keychain** |
| 弹层 | `bindSheet` | `.sheet` + `.presentationDetents` |
| 切角 | `clipShape(Path)` + **vp2px 换算坑** | `.clipShape(Path)`，坐标即点，无坑 |
| 网格 | `Grid`（**不给高度撑满父容器**） | `LazyVGrid`，无坑 |
| 图标 | `SymbolGlyph` | `Image(systemName:)` |
| 手势 | `PanGesture` | `DragGesture` |
| 返回 | `onBackPress()` | 系统边缘返回 + `NavigationStack` |
| 安全区 | `expandSafeArea` | `.ignoresSafeArea` / `safeAreaInset` |
| 空体请求 | 手动不发 `Content-Type` | `URLRequest` 无 body 时不设 |
