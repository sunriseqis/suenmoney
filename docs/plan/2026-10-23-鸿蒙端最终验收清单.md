# 鸿蒙端最终验收清单（上机时照着做）

> 代码侧全部完成，构建通过。以下每一项都需要**真机/DevEco**，按顺序做，
> 每项贴一张截图或一段输出到 `docs/reports/hw/` 下即可。

## 零、准备（一次性）

```bash
export DEVECO_CLI_CLT_PATH=/opt/clt/command-line-tools

# 1) 登录华为账号（我无法代做：需要你的凭据）
devecocli auth login

# 2) 生成调试签名并写入项目配置
devecocli signature generate

# 3) 构建（有签名后产物是已签名的 .hap）
cd hw-native && devecocli build

# 4) 装到真机（USB 调试打开）
devecocli run
```

产物路径：`hw-native/entry/build/default/outputs/default/`

## 二、H1 登录（3 项）

| # | 操作 | 期望 |

## 三、H2 流水（4 项）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 按月 / 按年 / 全部 三档切换 | 形态分别是：明细列表 / 12 月格 / 一年一格 |

## 四、H3 记账（5 项）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 列表顶部下拉 > 80vp | 抽屉弹出（这是唯一入口） |
| 2 | 选信用卡 + 日期设为次月 | **强调色显示「这笔会记在 X」** |
| 3 | 退款开关打开 | 金额前缀变 `-¥`，落库为负数 |

| 5 | 记两笔后再记一笔 | 分类与支付方式保持上次选择 |

## 七、H7 同步（3 项，最关键）

|---|---|---|
