## 一、移除已部署的测试服务（systemd）★ 用户明确要求

> **当前状态（2026-10-29）**：服务 `active` + `enabled`，监听 `0.0.0.0:5310`，
> 数据库 `/var/lib/suenmoney/suenmoney.sqlite`。**开发期间保留**——鸿蒙端连的就是它，
> 停掉会让验收中断。**开发结束（用户宣布收尾）时**按下面三步执行。

测试期为了长期在线，把服务注册成了 systemd 常驻单元 `suenmoney`（端口 5310）。
**项目收尾时必须移除**，否则会在目标机器上留一个自启服务。

```bash
# 1) 停掉并取消开机自启
sudo systemctl stop suenmoney
sudo systemctl disable suenmoney

# 2) 删除单元文件（按实际路径）
sudo rm -f /etc/systemd/system/suenmoney.service
sudo systemctl daemon-reload
sudo systemctl reset-failed suenmoney 2>/dev/null || true

# 3) 确认已彻底移除
systemctl status suenmoney          # 期望：Unit suenmoney.service could not be found
ss -lntp | grep 5310 || echo "5310 已释放"
```

**验收**：上面第 3 步两条都符合预期。
