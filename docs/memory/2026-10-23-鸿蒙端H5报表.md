## 二、环图为什么自绘

- ArkUI 没有 SVG，`stroke-dasharray` 那套 Web 办法用不上
- 只需要画圆弧，引图表库的代价（体积、样式对抗、生命周期）大于收益
- **Canvas 不会自动重绘** → 父组件传数据指纹 `signature`（维度 + 月份 + 总额 + 每段比例与颜色），
  `@Watch` 触发重画。指纹比逐字段比较更不容易漏

另外先画一圈底环：没有数据时也要有形状，否则整块会「缺一块」。

## 三、照 decisions 做的两件事

1. **排名行中间必须有占比条**：还款节奏与年度走势都用了 `Stack(底条 + 进度条)`。
   名称与金额摆两端、中间空一大块时，眼睛要横跨整行才能对上。
2. **涨跌榜只列「上期有数据」的分类**：全是新增的话没有可比性，文案写「新增」而不是 +100%。
