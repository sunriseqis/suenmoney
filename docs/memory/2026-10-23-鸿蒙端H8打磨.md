## 二、为什么单独做网络监听

`onForeground` 只覆盖「切回前台」。**Wi-Fi 断掉又恢复时应用一直在前台，不触发任何生命周期回调** ——
那三笔离线账会一直躺在队列里，直到用户手动点同步或切后台再回来。
所以必须订 `netAvailable`，且要记住「上一次是无网」才推（避免每次网络事件都打一次）。

```bash

devecocli auth login          # 你登录
devecocli signature generate  # 生成调试签名并写入 build-profile.json5
cd hw-native && devecocli build && devecocli run   # 装到真机
```
