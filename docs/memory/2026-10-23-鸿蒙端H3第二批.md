## 一、补齐四项

| 项 | 实现 |
|---|---|
| 消费日期 | `DatePickerDialog.show({ start, end, selected, onDateAccept })`，改日期后**重新取账期预览** |
| 编辑已有记录 | 流水行点击 → 抽屉切编辑态（标题「编辑」），保存走 `PATCH /api/expenses/:id` |
| 删除 | 编辑态出现「删除」→ `AlertDialog` 二次确认 → `DELETE`（软删必确认：用户看到的是「没了」） |
| 记住上次分类/支付 | `common/store/LastPick.ets`（preferences，key `suenmoney:last-pick`），**沿用前校验仍可选** |

## 二、两个细节

1. **记住上次只在成功后写**：记账失败不该影响下次默认值，所以 `LastPick.write()`
   放在 `createExpense()` 成功之后。
2. **编辑态回填金额用 `formatCents().replace(/,/g,'')`**：先把整数分还原成「元」文本
   （不带千分位，否则输入框里出现逗号）；退款符号用 `Math.abs` 去掉，
   再用 `isRefund` 开关表示 —— 与新建路径同一套状态机。

## 三、日期解析必须在本地时区

```ts
new Date(Number(y), Number(m) - 1, Number(d))   // ✅ 本地零点
new Date('2026-10-23')                          // ❌ 按 UTC 解析，东八区会早一天
```
