## 2. 关键架构设计与实现

### 2.1 多服务端与自动探测机制（`web/src/api/client.ts`）
- **持久化配置**：
  - `readServerUrls()` / `writeServerUrls(urls)`：支持保存多个服务端地址（自动清理尾部斜杠与空格）；
  - `getActiveServerUrl()` / `setActiveServerUrl(url)`：管理当前激活使用的服务器地址。
- **主动探活与故障转移探测**：
  - `probeServerUrl(url, timeoutMs)`：针对单一服务端发起 `/api/health` 探活，带严格超时（默认 2500ms），返回响应状态、耗时与错误说明；
  - `detectAndSwitchServer(urls, timeoutMs)`：严格遵循 **服务端 1 (内网/优先) -> 服务端 2 (备用/Tailscale) -> 服务端 3 (备用/公网域名)** 顺序依序探测，遇到第一个可用服务端立即激活连接，并广播网络状态变更；
  - `request<T>` / `downloadFile` 请求自适应重试：优先使用当前激活服务器；若发生网络层不可达错误，自动依序降级探测备用服务端，连通后无缝切换激活地址，保障无感使用；遇到 4xx/5xx 业务异常不误切服务器。

### 2.2 真实连通性状态管理（`web/src/stores/sync.ts`）
- 彻底废除原先仅读取浏览器 `navigator.onLine`（手机连 WiFi 但后端未起即被判定在线）的缺陷逻辑；
- `isOnline` 默认为 `false`，启动时与网络事件触发时调用 `checkConnectivity()` 进行真实接口握手；
- 挂载 25 秒定期探活任务：优先尝试把连接切回内网（服务端 1），一旦回家接入家庭 WiFi，自动从异地/公网无缝切回内网 IP；
- `runSync()` 执行前前置探活，避免盲目同步抛错。

### 2.3 极简「服务端设置」面板（`web/src/components/ServerSettingsPanel.vue`）
- 面板标题与设置页选项卡统一改名为 **“服务端设置”**；
- 右上角轻量指示：仅展示 `● 已连接` 或 `● 未连接` 状态胶囊；
- 清理掉所有旧版“待发送队列条数”、“同步版本号”、“上次同步时间”等技术噪音；
- 输入框精炼为 3 个固定插槽：
  - 服务端 1（优先 / 内网）
  - 服务端 2（备用 / 异地互联）
  - 服务端 3（备用 / 公网域名）
  并在当前连通的服务器旁标注 `● 当前连接` 标识；
- 底部操作栏严格仅保留 3 个动作按键：
  - `测试`：并发/顺序检测配置列表，测出可用项并提示毫秒延迟；
  - `保存`：持久化配置并触发后台平滑重连；
  - `同步`：触发本地离线 Outbox 补偿上报与服务端增量拉取。

### 2.4 设置页交互与连通性自动恢复（`web/src/views/SettingsView.vue`）
- 在移动端等分/滑动 Tab 栏中提供直观的 `服务端设置` 分区；
- 增加 `watch(activeTab)`：切换选项卡时自动清空历史错误信息；
- 监听 `onConnectivityChange`：当网络或服务器连通恢复时，自动清除旧的“无法连接到服务器”顶部报错，并无缝重新加载家庭成员与分类字典。

### 2.5 后端跨源预检与开发服务（`server/src/http/server.ts`）
- 解决 Fastify 默认同源拦截的问题，配置 `@fastify/cors` 允许局域网与 Capacitor 原生跨源访问（`origin: http://localhost`），正确响应 `OPTIONS` Preflight，允许 `Authorization` 与 `Content-Type` 自定义请求头；
- 后端服务以常驻守护模式启动并监听 `0.0.0.0:3310`，已实机验证 `/api/health`、`/api/sync/pull` 与 `/api/sync/push`。

## 4. 架构解耦与主动同步全时机落地（/grill-me 对齐）

### 4.1 Platform Adapter 抽象（未来随时一键拆库）
- 新增平台抽象层目录 `web/src/platform/`：
  - `env.ts`：运行环境动态感知，条件安全加载原生插件；
  - `lifecycle.ts`：抽象 Web `visibilitychange`/`pageshow` 与原生 `appStateChange` 为统一 `onAppResume`；
  - `network.ts`：抽象 `navigator.connection` 与网络切换为统一 `onNetworkChange`（支持 Wi-Fi ↔ 蜂窝移动网络）；
  - `hardware.ts`：拦截物理返回键 `setupHardwareBack`；
  - `haptics.ts`：触感反馈 `triggerHaptic`。
- 业务层零原生耦合：所有业务组件（`App.vue`、`stores/sync.ts` 等）彻底移除了 `@capacitor/*` 的静态 import，纯 Web 部署无需任何原生包，未来 Android 壳代码可随意独立拆出仓库。

### 4.2 主动同步全时机覆盖与防抖
- 应用启动或恢复前台：自动拉取最新变更；
- 网络环境变更（Wi-Fi ↔ 移动蜂窝）：触发网络状态探活并自动补偿同步；
- 客户端操作实时同步：在 `uiStore.markDataChanged()` 中接入 `syncStore.scheduleSync(300)`，实现添加/编辑/删除明细、增删改计划与分类、支付方式以及待办确认/跳过时，操作后 300ms 自动在后台无感推送到服务端。

### 4.3 服务端设置面板动态化与去噪
- 卡片固定置顶于「系统」Tab，不占用全局主 Tab；
- 支持动态加行（点击 `+` 按钮增加新地址，非死板三行）；支持上下微调与拖动排序；
- 生效中的服务器右侧内嵌小绿点（`●`）；
- 移除卡片内部红色报错条，标题右侧使用轻量微型标签（`在线` / `离线`），彻底杜绝网络颠簸引起的页面抖动。

### 4.4 编译死锁问题根治
- 排查并终止了后台占有 Gradle 锁的旧守护进程（PID 2582784）；
- 统一使用 `--no-daemon` 纯净构建，构建时间稳定在 40~50 秒以内，安装实机后双向同步 97 笔真实流水成功。
