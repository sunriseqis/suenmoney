# 2026-10-23 鸿蒙端 H6 第二批：编辑弹层（H6 收尾）

> 前序 `2026-10-23-鸿蒙端H6设置.md`

## 一、做了什么

`components/settings/SettingsScreen.ets` 加三张 `bindSheet` 表单 + `Api` 补十一个写方法。

| 弹层 | 能力 | 接口 |
|---|---|---|
| 分类 | 新增类别 / 新增分类 / 编辑 / 停用 | POST/PATCH `/api/categories` |
| 支付方式 | 新增 / 编辑 / 合并 / 停用 | POST/PATCH/POST merge/DELETE `/api/payment-methods` |
| 计划 | 新建（分类、支付、每期金额、期数、自动入账）；终止 / 删除 | POST `/api/plans`、POST `:id/end`、DELETE `:id` |

入口按移动 Web 的用词：**「新增类别」（一级）/「新增分类」（二级）**。

## 二、颜色规则落到了表单里

- 一级分类：显示 8 个色号色板，选中即存 `color`
- 二级分类：**不显示色板**，改为一句话「颜色跟所属一级分类走」，
  提交时 `color: ''` 让服务端保持继承

这是 decisions 里那条「图标取自己的、颜色跟一级走」在表单层的体现 ——
如果二级也能选颜色，用户会选出一个「和父级不一样」的二级，规则就破了。

## 三、危险动作继续收进「更多」

计划行的「终止计划 / 删除计划」用 `bindMenu` 挂两个 `MenuItem`，
与 H6-D1 的待办「忽略本期」同一个模式。
