## 二、为什么分类筛选只列一级

二级分类挂在各自一级下，全列出来会出现「外卖 / 下馆子 / 咖啡…」十几个按钮挤成一片，
而用户想筛的通常是「餐饮」这一类。服务端 `categoryId` 传一级 id 时，
二级分类的流水也会命中（服务端按一级归属过滤）。

## 三、离线路径的过滤必须自己写

线上过滤由服务端做；断网时 `ExpenseDao.byMonth()` 只按月份取回全量，
条件得在内存里筛：

- 分类：二级行要**上溯到一级**再比（`cat.parentId !== '' ? cat.parentId : row.categoryId`）
- 支付 / 记录人：直接比 id
- 搜索：分类名或备注包含关键词

## 四、排序在同额时保持日期序

`sort((a,b) => b.amountCents - a.amountCents)` 在 JS 引擎里对相等元素不保证稳定，
会出现「每次刷新顺序抖动」。日期排序加了显式三态比较（`<` / `>` / `0`），
同一天的顺序才稳定。
