## 踩的坑（都修了）

1. **类丢失**：第三批 python 替换锚点文字不匹配，`btn-v4/panel-v4/input-v4` 的 v5 定义
   没写进 base.css，而登录页一直引用 → 变成空类。教训：替换后要 grep 验证**目标类存在**。
2. **非法选择器**：`:root[data-theme='light'])` 多一个右括号，Tailwind build 直接报
   「Missing opening (」——构建期暴露是对的，但说明手写 CSS 选择器要仔细。
3. **minify 会改值**：`0px 0px` 被压掉（`4px 4px 0px 0px #1E293B` → `4px 4px #1e293b`），
   验证产物时按等价语义查，别按字节查。
4. 生成器 `d.shape.chamferSm` 引用错层 → 改 `d.chamferSm` + 兜底默认值。
