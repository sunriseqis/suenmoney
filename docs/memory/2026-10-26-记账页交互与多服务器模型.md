# 2026-10-26 记账页交互重做 + 多服务器模型 + 顶部/底部布局裁决

本轮全部是用户当面反馈后逐条改的，每条都在模拟器（1280×2832，cyber）上量过。

## 一、布局：顶部与底部（用户裁决）

| 结论 | 说明 |
|---|---|
| 顶部**不渲染**品牌条 + 标题栏 | logo / `SuenMoney` / 页面标题 / 主题切换 / `+记一笔` 全部去掉；流水页与二级页一样 |
| 二级页返回改**系统返回手势** | `onBackPress()`：流水页→交系统回桌面；年度报告→回报表；其余二级页→回流水 |
| **不渲染 build-stamp 页脚** | Web 移动端 `.side-foot` 是 `display:none`（app.css:741），之前无条件渲染固定吃掉 ~105px |
| 内容**铺到物理底边** | `setWindowLayoutFullScreen(true)` + 根容器 `expandSafeArea([SYSTEM],[BOTTOM])`；状态栏高度用 `getWindowAvoidArea(TYPE_SYSTEM).topRect` 量出来自己补 |
| 内容列 `padding bottom` 64 → 12 | Web 的 64px 是**浏览器滚动留白**，原生没有浏览器 |

**实测**：内容最低点 y2678 → y2790（屏 2832），流水页可见行 1 → 5 行。

## 二、溢出与跳动

- **概况/报表的期间行把日期顶出卡片**：根因是 `label.constraintSize({minWidth})`（概况 92vp=331px、报表 116vp=418px）
  加箭头 38vp 把行撑爆。改成期间行 `.layoutWeight(1) + justifyContent(End)`、label 自己 `.layoutWeight(1)`
  吃余量、箭头 30vp。实测两个屏的 `›` 右边缘都正好 1186 = 卡片内边界（超出 0）。
- **设置页切 tab 整屏上下跳**：内容是**比视口短**时（设备区只有几张卡），Scroll 会把内容列**垂直居中**。
  给内容列 `constraintSize({ minHeight: '100%' })` + `justifyContent(Start)`，Scroll 外面再包一层撑满高度的
  Column（内层 `layoutWeight(1)`）。实测两个 tab 的 tab 行都在 y157。

## 三、记账抽屉（用户语义纠正）

用户原话：「有 X 有个 ok 按钮有个保存按钮，我理解 ok 就是保存了，但实际不是」。

- **OK 键原本是坏的**：`press('OK')` 掉进了数字分支，按了什么都不发生。改成 **`OK` 文案为「保存」、执行保存**，
  `canSave()` 为假时置灰。
- **删掉底部按钮行**（取消 + 第二个保存）；编辑态的「删除」移到标题行右侧。
- **`showClose: false`**：系统 X 压在内容右上角，和「退款冲销」一起盖住金额；
  「退款冲销」改到标题左侧紧跟标题。
- 抽屉高度 `SheetSize.LARGE` → **`FIT_CONTENT`**（贴合内容，既不留白也不撑大键盘），键盘固定 210vp。
- **常用分类快捷条按键盘列宽重排**：第一格 62vp（对齐支付列）+ 1vp 竖线 + 4 等分（对齐 `7 8 9 ←`，
  `columnsGap 5` / `padding-left 6`），格高 40vp，**格内左图标 + 右分类名**（图标走内置 Symbol，
  二级颜色跟随一级），取 5 个正好一行。

## 四、图标

- 报表页图标错乱：`.width(30).height(30)` 直接加在 `SymbolGlyph` 上会贴左上角；
  流水页是 `Stack(){...}.width(34).height(34)`。改成同样的 Stack 包裹 → 实测图标 60px 在 105px 徽位里 dx=dy=0。
- **二级分类颜色跟随一级**：设置页加 `parentColor()`（= Web `PCatIcon` 的 `colorName` 用父分类名），
  记账页快捷分类加 `catColorOf()`。实测选「交通」后 4 个二级图标全是 `#E07060`。

## 五、多服务器（模型照 `/home/suenmusic/web/src/api/servers.ts`）

suenmusic 的做法：
- `ServerCandidate { label, url }`，**候选是用户自己维护的列表**（第一条优先级最高）；
- `probeServer()` 打 `/api/health`：**第一条 1.5s 独占**，其余 3s 并行；
- `failoverIfNeeded()` + **3s 冷却**；旧单地址自动迁移成列表首项；
- **前提写得很明确：多条路径指向同一套后端（同 DB / 同 JWT）→ 换路径不需要重新登录。**

本端据此改：
- 登录页：三个固定槽 → **一个输入口 + 测试按钮**（登录时落库为候选首项）；
- 设置 → 设备 → 服务器：**用户自维护列表**，每行地址 + 连通点 + 「生效」+ `×`，
  底部「+ 添加服务器」，空列表给空态；
- **保存不清 token、不跳登录页**（上一版我按「换了后端要重登」做过，看了 suenmusic 才确认是错的）。

## 六、踩过的坑（本轮新增）

1. **`.overlay()` 会铺一层全屏命中区**：下拉指示器最初用 `.overlay()` 挂根容器，
   结果整页点击（含 概况/报表/设置 链接）全被挡住。改成 Stack 兄弟节点 + `hitTestBehavior(HitTestMode.Transparent)`。
2. **`Stack({alignContent: Alignment.Bottom})` + 内容短** = 整屏被推到底部居中。
   这也是「切 tab 来回跳」的真凶之一，不只是 Scroll 的问题。
3. **多参数 `@Builder` 不刷新**：服务器槽位统一用「单对象 + `$$`」传（`SrvSlot { index, value, state }`）。
4. **`@Builder` 装饰器被替换文本吃掉**：用 `s.replace('  updateCard() {', ...)` 插入新 builder 时，
   原来的 `@Builder` 行留在了新注释前面，导致 `updateCard` 少了装饰器、编译报 `';' expected`。
   插入 builder 时要把**注释 + @Builder 一起**作为锚点替换。
