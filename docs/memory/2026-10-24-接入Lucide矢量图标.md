# 2026-10-24 鸿蒙端接入 Lucide 图标（不转字体，用 Path 直接画）

## 背景

Web 端分类/支付图标是 Lucide 组件（`<component :is="LucideIcon">`），鸿蒙端之前没有图标资产，
分类徽位画的是**单字标记**（食/车/居/卡…），和 Web 视觉差得很远。用户要求"直接用 Lucide"。

## 为什么不用图标字体

走过两条死路，记录下来免得重走：

1. **SVG → TTF → `font.registerFont`**：Lucide 是描边路径，字体 glyph 只认填充轮廓，
   必须先做 stroke→outline。试了 `svg-path-outline`（基于 makerjs）在这个环境直接 OOM，
   `svg-outline-stroke` 需要原生 canvas 依赖装不上。
2. **`SymbolGlyph` + `symbolRegister`**：需要华为 HM Symbol 格式的 TTF + 分层动效 JSON，
   官方 SDK 里没有格式文档和工具链，手搓不现实。

## 最终方案：ArkUI `Path` 组件直接吃 SVG 的 d

```ts
Shape() {
  Path()
    .commands(pathD)                  // 就是 <path d="...">
    .fill(filled ? color : '#00000000')
    .stroke(color)
    .strokeWidth(2)
    .strokeLineCap(LineCapStyle.Round)
    .strokeLineJoin(LineJoinStyle.Round)
}
```

好处：几何与 Web **完全同源**，描边色**运行时可染**（分类 16 色直接传），
不需要字体、不需要 PNG、不需要图标资产目录。

### 路径数据怎么来的

`docs/design/icons/lucide/*.svg`（86 个，从 `lucide-static` 的 jsdelivr CDN 拿的；
GitHub raw 大量超时）→ 机械转换成一条 path d：

- `<path d>` 直接用
- `<circle>` / `<ellipse>` → 两段圆弧闭合
- `<rect rx>` → 圆角矩形（4 段 h/v + 4 段 a）
- `<line>` / `<polyline>` / `<polygon>` → M/L/Z

产物 `entry/src/main/ets/common/ui/IconPaths.ets`（约 26KB），生成脚本逻辑见本文末尾要点。

支付品牌（支付宝/微信/云闪付/京东/抖音/银行卡）是 Web `payment-icons.ts` 里 1024 坐标系的
**填充**路径，等比缩到 24 单位（先确认过它们只用 M/L/H/V/C/S/Z、不含弧线标志位，所以
"所有数字同比缩放"是安全的）。

## 三个 ArkUI 坑（都是设备实测确认的）

1. **`fill(Color.Transparent)` 和 `fillOpacity(0)` 都不能表达"只描边"** —— 会画成实心块。
   只有 **ARGB 全零 `'#00000000'`** 才是真正的透明填充。
2. **`Shape.viewPort` 的缩放不生效** —— 图形按原始 24 单位画，比徽位还大。
   换成 `Path` 固定尺寸 + `.scale()`。
3. **`Path` 的 commands 坐标单位是 px，不是 vp** —— 和顶卡 `clipShape` 那个 bug 同源。
   缩放比要写成 `vp2px(iconSize) / (24 + strokeW)`。

   标定数据（同一图标，只改 iconSize）：
   | iconSize | 墨迹 |
   |---|---|
   | 12 | 46px |
   | 20 | 78px |
   | 28 | 110px |

   线性 3.9px/vp，比预期的 `vp2px` 大 8% —— 因为描边向外扩 `strokeW/2`。
   除以 `(24+strokeW)` 后，20vp 正好落在 **72px** ✓（本机密度 3.6）。

## 接入点

- 流水行分类徽位：44px 徽位 + 12% 分类色底 + 45% 描边 + **图标本体 20px**（R138）
- 设置页计划卡身份图标（R121）
- 设置页支付方式列表头像
- 记账抽屉支付快捷胶囊（品牌图标 + 品牌色）

## 验收数据（设备实测）

- 5 个流水行图标墨迹：71 / 74 / 74 / 79 / 72 px ≈ 20vp ✓
- 图标墨迹覆盖率：6.3% ~ 9.8%（描边型；填充型会在 40% 以上）→ 确认画的是描边不是实心

## 复用结论

1. **想验证"到底是描边还是填充"，量墨迹覆盖率最省事**：描边 ≈10%，填充 ≥40%。
   光看 ASCII 缩略图会被抗锯齿骗。
2. ArkUI 里凡是 `Path`/`Canvas` 的坐标都是 **px**，凡是布局属性都是 **vp**，混用必出鬼。
3. 部署脚本要校验 **ets 和 resources 两类文件**的 sha256：只同步 ets 时，换字体/换资源
   会静默不生效，白测一轮。
