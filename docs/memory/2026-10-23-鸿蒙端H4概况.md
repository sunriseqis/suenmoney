## 二、几条刻意的取舍

| 取舍 | 理由 |
|---|---|
| 待办颜色标记只给**左侧一条 3px** | decisions：紧急度用一条色条表达，整卡染色会让页面全是颜色，紧急度反而看不出来 |
| 热力用**单色透明度**而不是彩虹渐变 | 分类色已经占满了色相；热力再上色会和「这个月的支出构成」混淆 |
| 构成只画堆叠条，不画环图 | 环图是报表页的职责；同一份数据在一个应用里出现两次，才是「信息太少」的真正原因 |
| 概况不显示说明式文字 | 判据：这句话改变你要做什么吗 |
