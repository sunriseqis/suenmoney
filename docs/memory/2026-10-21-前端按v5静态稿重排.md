# 2026-10-21 前端按 v5 静态稿重排（布局级）

> 用户批评：「你这不还是在旧前端套嘛，静态啥样就是啥样，功能不等于布局，
> 保留每页的功能，布局、排版、大小、样式该改就改。」
> 参考：`docs/design/v5-design-preview.html`（用户确认版）

## 做法

**功能绑定保留，布局/排版/大小照静态稿重做**。分两路：

1. **外科手术**（逐个页面）：单行类名替换，绝不整块替换。
   期间两次整块替换误删功能块（概况页档位切换/提醒条 164 行），
   都靠 git checkout 恢复。此后立规矩：**只做单行替换，替换后立即
   grep 目标类 + 功能块数量 + 行数对比**。
2. **全局兜底**：14 个组件里 200+ 处旧式类（rounded-md/lg/sm、bg-subtle、
   ring-line）不改模板，在 `app.css` 末尾 `@layer utilities` 做一次性重解释
   （与 Tailwind 工具类同层、源码在后即胜出 —— 放 @layer base 会被压掉，
   实测规则位置 158971 > Tailwind 125691 才确认胜出）。
