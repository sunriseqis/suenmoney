## 二、三档三形态（照移动 Web）

- **按月**：`List` + `ListItemGroup`，按消费日分组、组头带日小计；每段 100 笔，底部「加载更多」
- **按年**：`Grid` 3 列 12 个格（月 + 金额 + 笔数），点格进该月
- **全部**：`Grid` 2 列一年一格（年 + 金额 + 笔数），点格进该年

## 三、离线 A 档（读）

触发：`ApiClient` 抛 `ApiError.kind === 'network'` → 置 `offline = true`，改从本地库取：

- 列表：`ExpenseDao.byMonth()`（`substr(repayment_date,1,7) = ?`，**与报表口径同一列**）
- 合计：`ExpenseDao.monthTotal()`
- 构成（H4 用）：`ExpenseDao.monthByCategory()`

页面顶部显示一行「离线：显示本地缓存」，不做静默降级 —— 用户得知道自己在看缓存。

## 四、颜色规则：存色号不存色值

`Palette.slotOf(colorField, categoryId)`：显式色号优先，没有就按 id 哈希。
`chartColor(tokens, slot)` 再从当前主题取 chart1..8 —— 换主题时分类色整体重排，
这正是「存色号」的意义（存死色值会让同一分类在深浅主题下颜色对不上）。
