## 十五、我在换皮过程中动过、需要你确认的点

| 项 | 我做了什么 | 风险 |
|---|---|---|
| 设置页 tab | 5 个 → 分组显示为「账目 / 数据 / 家庭」 | 分组标题与原「系统」语义变了 |
| 8 处设置条目 | `row-v5 settings-row`（grid 40px+1fr+auto） | 原本 flex 布局的行可能错位 |
| 概况页 main | 桌面改双列 grid（热力 ‖ 当期事实） | 高度不等时可能留白 |
| 流水页 main | `order` 把构成卡提到列表**上方** | 提交信息写的是「下方」，代码是上方，需你定 |
| 旧式类重解释 | 全站 `rounded-md/lg/sm` → 切角/16px 圆角 | 个别原本要小圆角的地方变大了 |
| 图标描边 | 深色 1.5 / 浅色 2.5 全站生效 | 细线图标在深色可能偏细 |
