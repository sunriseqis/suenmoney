## 常见退回原因（Agent 自检时先看这里）

| 症状 | 判据 |
|---|---|
| 报告写「与 Web 一致」而没给数字 | 直接退回，要求逐笔对照（笔数 / 合计 / 每行金额） |
| 截图没标设备与分辨率 | 退回补标 |
| 对照截的是桌面 Web | 退回重截 ≤860px 的移动形态 |
| 改了 `vectors.json` 的期望值 | 视为改契约，退回并说明原因 |
| 「已知问题：无」但明显没验证 | 退回，要求写清验证方式 |
| 顶部出现标题 / 记一笔 / 主题按钮 | 违反移动 Web 对齐，退回 |
| 移动端做了构成卡 | 违反移动 Web 对齐，退回 |
