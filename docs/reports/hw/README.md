# 鸿蒙端验收报告目录

Agent 每完成一个阶段，在此目录提交一份验收包：

```
docs/reports/hw/H<阶段号>-<主题>.md
例：H0-工程与底座.md、H2-流水.md
```

格式固定见 `docs/plan/2026-10-22-鸿蒙端开发任务书.md` §五。
证据（截图 / 录屏 / 构建日志）放 `docs/reports/hw/assets/H<阶段号>/`。
