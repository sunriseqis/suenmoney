## iOS 完全缺失的功能

- **保存后轻提示**：`onSaved` 里的 `showToast(savedId === '' ? '已保存' : '已记账')` 整个缺失，记完账无任何成功反馈。
- **保存后列表回顶**：`this.scroller.scrollEdge(Edge.Top)` 无对应实现（iOS 侧连 `ScrollViewReader` 都没引入），新记录落在顶部但视口不动。
- **保存后 `editingRow` 复位**：鸿蒙 `onSaved` 里显式 `this.editingRow = null`；iOS 只在创建请求时清空，保存路径没清，下次打开抽屉可能沿用上次的编辑对象。
- **抽屉取消回调 `onCancel`**：鸿蒙 `ExpenseEditor({ props: { onSaved, onCancel } })` 有取消分支（关抽屉 + 清 `editingRow`）；iOS 的 `ExpenseEditor(editing:onSaved:)` 没有取消回调。
- **列表加载态**：`monthCard` 的 `if (this.loading)` → 「加载中…」12 `ink3` 居中 `padding(34)` 分支缺失，加载中列表区一片空白。
- **搜索框聚焦视觉**：`searchFocused` 的 `accent` 描边 + `3px 3px 0 accent` 硬阴影未实现（`searchFocused` 只喂给 `.focused`）。
- **聚焦自动展开高级区**：`onFocus` 里 `advOpen = true` 缺失，点搜索框后档位/期间/筛选仍收着。
- **搜索占位色**：`placeholderColor(ink3)` 未设，占位文字走系统灰，与 `#94A3B8` 不同。
- **「收起」独立按钮**：被合并进「筛选 / 收起」切换按钮，原设计是搜索行右侧独立「收起」，高级区里另有独立「筛选」。
- **筛选组顶部虚线分隔**：`border top 1 dashed line` + `padding top 14` + `margin top 6` 三者全缺，筛选组与高级区糊成一片。
- **筛选胶囊选中硬阴影**：candy 下 `offsetX/offsetY = 2`、色 `line2` 的实体偏移缺失，选中态只剩底色。
- **待同步条数上报**：`pendingSync` / `sharedPending` / `refreshPending()` 全无实现 —— iOS 里 `@State private var pendingSync: Int = 0` 声明后从未赋值，是死状态；鸿蒙在 `aboutToAppear` 与 `onSaved` 后都会拉 `Outbox.pendingCount()` 并写回 AppStorage。
- **下拉位移累计值 `pullMax`**：鸿蒙有独立字段 + `onActionStart` 清零 + `event.offsetY > pullMax` 累积；iOS 直接用 `value.translation.height`，没有累计，回拉会倒退。
- **下拉指示器的裁切揭示**：鸿蒙用固定 `markSize: 34` 的 logo + `.height(52 * p).clip(true)` 逐段露出；iOS 用 `BrandMark(34 * p)` 缩放 + `p > 0.35` 才渲染小字，是「放大出现」而不是「拉出多少看多少」。
- **`SheetSize.FIT_CONTENT` 贴合内容**：iOS 恒 `.presentationDetents([.large])`，短表单下方留大片空白。

## iOS 完全缺失的功能

- **年度报告年份由报表页传入**：鸿蒙 `annualYear`（`@StorageLink` + `@Watch('reload')`），iOS 无此通路，`year` 只在本地 `@State` 初值为当前年。
- **hero 金额三档自适应字号**：34 / 28 / 22（阈值 8 / 10 字符），iOS 恒 34。
- **¥ 符号独立降档**：`heroSize() * 0.5` = 17 / 14 / 11，`ink2` 着色，与数字同排底对齐；iOS 把 ¥ 塞进 34pt 正文。
- **年度全貌卡 candy 深墨描边**：`line2` = `#1E293B`、宽 `borderW` = 2；iOS 用 `line` = `#E2E8F0`。
- **orb 日历球阴影**：candy `2px 2px 0 #1E293B`；cyber `radius 10 / offsetX 0 / offsetY -2 / rgba(0,255,136,0.4)`。
- **空月灰柱**：`surface3`（candy `#F1F5F9` / cyber `#16162a`），用于区分 0 支出月份。
- **柱高 `Math.round` 取整**：iOS 输出小数高度。
- **柱顶仅上圆角**：`topLeft 3 / topRight 3 / bottom 0`。
- **月份标签纯数字 + 9.5pt**：iOS 是 `N月` + 8.5pt。
- **三段统计的裸列样式**：无底色、无内距、左对齐、值 21/18 display Bold。
- **topCat 百分比按 `cents / total` 现算 + `Math.round`**：iOS 用服务端 `ratio` + `Int` 截断。
- **topCat 表头"全年"文案**（含 `letterSpacing 1.52`）。
- **topCat 名称省略号**（`maxLines(1)` + `Ellipsis`）。
- **全屏 10 处 `tnum` 等宽数字**。
- **年份快选弹层"无阴影"**（iOS 反而多画了 `3px 3px 0 #E9EEF6`）。
- **iOS 多出（基准没有）**：`全年支出` 标签、当前月高亮分支、topCat 34×34 图标块、`minimumScaleFactor(0.7)`、`errorText` 死状态。

## iOS 完全缺失的功能

- **本月已支出（R107）**：`Api.monthlyReport(month)` + `monthSpentCents` 状态 + `本月已支出` 行 + `—` 占位，iOS 整段没有（`Api.monthlyReport` 在 iOS 侧存在，只是本屏未调用）。

- **支付方式快捷列**：键盘左侧 `payments.slice(0,4)` + 常驻「更多」按钮，iOS 完全没有这一列，也没有 `更多` 这个入口。
- **`shortName()` 支付方式精炼**：`招商银行信用卡 → 招行`、`建设银行 → 建行`、超 3 字截前 2 字，iOS 无此函数（因为左列不存在）。

- **`←` / `清空` 文案**：iOS 直接把 `B`、`C` 显示出来，没有 `key === 'B' ? '←' : '清空'` 的映射。
- **保存键跨两行**：`rowStart(3)/rowEnd(4)/columnStart(4)/columnEnd(4)`，iOS 无跨行概念。
- **删除二次确认弹层**：`AlertDialog.show` 带「删除这笔记录？」+ 明细 + 取消/删除，iOS `confirmDelete()` 直接删。
- **账期预览的实时合计**：预览行右侧 `formatYuan(isRefund ? -cents : cents)`，iOS 无。
- **`账期未取到` 占位**：`preview === null` 时的兜底文案，iOS 直接不渲染整行。
- **非信用卡的还款日文案**：`还款日 {repaymentDate}`，iOS 用 `isCredit` 把整行挡掉了。
- **`monthLabel()` / `dateShort()` 中文格式化**：`2026-11-28 → 2026 年 11 月` / `11月28日`，iOS 用 `prefix(7)`、`dropFirst(5)` 得到 `2026-11`、`11-28`。

- **`railChildren()`**：一级下无二级时回退为一级自己，iOS 无。
- **`catColorOf` 的 root-self 分支**：`root.id === cat.id` 时用 root 自身色，iOS 只判 `parentId`。
- **`findCategory` 对停用分类的容忍**：鸿蒙保留全量字典所以编辑态能回填名字，iOS `filter { $0.isEnabled }` 后回填成「选择分类」。
- **`lineColor()`**：`isCyber ? tok().line : outlineStrongOf(false)`（candy `#1E293B`），iOS 直接用 `tokens.line2`，无 `outlineStrongOf` 这一层。
- **`outlineStrongOf` / `FOCUS_RING` 的引用**：`#6f6f92` / `#5DB8FF` 在 iOS 本屏一次都没出现。
- **键盘 / 快捷格硬阴影**：`parseShadow('2px 2px 0 ' + tok().line)`，iOS 键帽与快捷格均无阴影。
- **`Divider` 竖向分割**：键盘左右、快捷条左列后各一条 1vp 竖线，iOS 均无。
- **`saving` 对按键的阻断**：鸿蒙 `press('OK')` 里 `!this.saving` 双保险，iOS 保存键 `.disabled` 是死代码，仅靠 `press` 内部判断。
- **`onCancel` 属性**：鸿蒙 `ExpenseEditorProps` 声明了 `onCancel`（当前 build 未使用），iOS `init` 无此参数，外壳无法感知取消。
- **`expenseCount` 排序依据**：鸿蒙 `quickCats` 依赖 `CategoryNode.expenseCount`，iOS 从不读该字段。
- **`toDateKey()` / `parseDateKey()` 的本地时区口径**：鸿蒙自写 `new Date(y, m-1, d)` 构造零点，iOS 走 `Calendar.current`，跨时区/夏令时边界可能差一天（本屏只用 `parseDateKey`）。
- **错误提示位置约束**：鸿蒙把 `errorText` 固定在键盘上方，iOS 放在最底部，安全区下可能被裁。

## iOS 完全缺失的功能
- **输入框焦点高亮**：鸿蒙 `FOCUS_RING = '#5DB8FF'` + 宽度 2 的聚焦描边分支，iOS 侧 `UiStyle.swift` 连 `FOCUS_RING` 常量都没有，`LoginView` 也没有任何聚焦视觉。
- **`outlineStrongOf(_:)` 令牌函数**：鸿蒙 `UiStyle.ets:134` 提供 cyber `#6f6f92` / candy `#1E293B`，iOS `UiStyle.swift` 无此函数，三个可交互控件直接用 `tokens.line2`（cyber 下 1.32:1）。
- **`fieldBgOf(...)` / `fieldBorderWOf(...)` 统一入口**：鸿蒙有这两个函数收敛「cyber 用 surface2 + 1.5 描边」的规则，iOS 在 `LoginView` 里内联写 `isCyber ? tokens.surface2 : tokens.surface` 与 `isCyber ? 1.5 : 1`，规则散落在视图里，后续改主题会漏。
- **登录按钮的禁用态视觉**：鸿蒙靠 `.enabled(false)` 拿到 ArkUI 默认置灰；iOS `.disabled(busy)` 对自定义 label 无任何外观变化。
- **登录按钮的胶囊形状**：鸿蒙 `Button` 默认 `ButtonType.Capsule`（22 半径），iOS 用 `rMd`（14/0），没有胶囊分支。
- **整屏固定布局（不可滚）**：鸿蒙 `height('100%')` + `justifyContent(FlexAlign.Start)` 的固定版式，iOS 用 `ScrollView` 替代，没有等价实现。
- **页面背景铺满安全区**：鸿蒙本页没有 `expandSafeArea`（`MainPage.ets:136` 才有 bottom），iOS 用 `ignoresSafeArea()` 铺满，两端对状态栏区域的处理不同。
- **「登录」标题的居中版式**：鸿蒙是居中（Column 默认对齐的结果），iOS 没有居中版本，只有左对齐。
- **服务端地址框的焦点跟踪**：鸿蒙只有 `usernameFocus` / `passwordFocus` 两个焦点状态，iOS 的 `Field` 枚举多一个 `.server`；两端焦点覆盖范围不一致（此项为 iOS 多出，鸿蒙缺失）。
- **首次初始化共用表单的语义**：鸿蒙文件头注释声明「登录与首次初始化共用一张表单」，iOS 明确 `U17 不做首次初始化`（`LoginView.swift:12`）。本文件里鸿蒙并没有注册入口按钮，**实际 UI 无差异**，仅产品语义不同 —— 若后续鸿蒙补注册按钮，iOS 会缺这一整块。

## iOS 完全缺失的功能

- 系统返回手势 → 路由回退：`AppState.goBack()` 无任何调用方，RootView 也没有 `NavigationStack`（二级页无法回到流水页）
- 状态栏底色跟随主题（`statusBarColor = tokens.bg`）
- 状态栏文字颜色跟随主题（`statusBarContentColor = tokens.ink`）
- 底部手势条底色/前景色跟随主题（`navigationBarColor` / `navigationBarContentColor`）
- 沉浸式全屏（`setWindowLayoutFullScreen(true)`）与自补状态栏高度（`statusBarVp`）
- 底部安全区展开（`expandSafeArea([SYSTEM], [BOTTOM])`）：内容到物理底边
- 运行时字体注册与注册失败日志（`font.registerFont` + `hilog.warn`）
- `AppStorage` 进程级跨屏键：`'activeScreen'` / `'pickMonth'` / `'createRequest'` / `'statusBarVp'`
- `onBackPress()` 在流水页返回 `false` 的「退到桌面」语义
- 独立 `pages/LoginPage` 页面 + `loadContent` 二选一的登录门
- `startWindowBackground` 启动窗口底色
- `ohos.permission.VIBRATE` 对应的振动能力声明
- 横屏方向支持（鸿蒙未限 orientation，iOS 仅 Portrait）
- 令牌函数：`outlineStrongOf`（12 处调用）、`fieldBgOf`（4 处）、`fieldBorderWOf`（5 处）、`FOCUS_RING`（5 处）、`cardRadiusOf`、`CARD_PAD`、`CUT_CARD/CUT_BTN/CUT_ORB/CUT_LOGO`、`cyberClipCommands`
